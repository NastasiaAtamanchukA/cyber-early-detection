# Финальная полировка UI

В этой версии дополнительно доработаны:

- представление алертов: вместо плотного старого карточного вида используется широкий list-grid с мета-информацией справа;
- подробные карточки: добавлена кнопка разворота модального окна на весь экран;
- дашборд: рисковые хосты выводятся по 3 с внутренним листанием;
- статусы: добавлены цветные бейджи для новых, взятых в работу и закрытых сущностей;
- инциденты: после взятия в работу появляются кнопки быстрого реагирования: изолировать хост, заблокировать УЗ, запросить логи, создать задачу SOC и отправить уведомление администратору.
