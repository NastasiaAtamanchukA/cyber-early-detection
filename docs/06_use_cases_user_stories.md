# Use Cases / User Stories

| ID | Роль | Хочу | Чтобы | Критерий приемки |
| --- | --- | --- | --- | --- |
| US-01 | SOC-аналитик | видеть список событий безопасности | быстро находить подозрительную активность по хосту, пользователю и типу события | GET /api/v1/events возвращает события; UI показывает таблицу событий |
| US-02 | SOC-аналитик | видеть алерты и критичность | приоритизировать расследование | GET /api/v1/alerts возвращает severity/status/title; UI подсвечивает критичность |
| US-03 | SOC-аналитик | открывать карточку алерта/инцидента | понимать причину риска и затронутые активы | Карточка содержит event, host, user, risk_score, recommended action |
| US-04 | Администратор | отправлять событие через API | проверять ingestion и ML scoring | POST /api/v1/events/ingest создает event и при необходимости alert |
| US-05 | Проверяющий | запустить проект одной командой | быстро проверить демо без ручной настройки | docker compose up --build -d поднимает все сервисы |
| US-06 | Разработчик | видеть падающие проверки в CI | быстро исправлять ошибки качества | GitHub Actions показывает backend/ml/frontend job и причину падения |
| US-07 | Разработчик | иметь документацию по Git flow | вести понятную историю изменений | Коммиты соответствуют Conventional Commits |
