# Как вручную создать GitHub Release v0.1.0

1. Перейти в репозиторий: https://github.com/NastasiaAtamanchukA/cyber-early-detection
2. Справа на странице репозитория открыть **Releases**.
3. Нажать **Draft a new release**.
4. В поле **Choose a tag** ввести `v0.1.0`.
5. Если тега еще нет, выбрать **Create new tag: v0.1.0**.
6. В поле **Target** выбрать ветку `main`.
7. В поле **Release title** указать `Cyber Early Detection v0.1.0`.
8. В поле описания вставить текст из `docs/11_release_notes_v0.1.0.md`.
9. Если есть ZIP/презентация/итоговый документ, можно приложить их в блок assets.
10. Не отмечать pre-release, если это обычная финальная учебная версия.
11. Нажать **Publish release**.
